## 示例 1：技术决策（带「因」）

```
【点 2】seq 2300-2500 · 2026-10-25 15:45-16:10
事：自测 + 读源码。自测：压缩事件 78 个、记忆库 140 条、日记库断更在 10-23。
读源码：thresholdTokens = min(窗口×80%, 窗口-输出预留-headroom) = 678K，实际 67.8% 就压。
选：不改阈值（安全余量合理），只把 retainRatio 从 16% 调到 25%——原文多留、台阶更密。
因：页面显示"68%"就是快压了，两个分母不一样。
关键词：「67.8%」「retainRatio 0.25」「两个分母」
```

## 注意

- 点的**长度**是硬约束（≤200 字）——超了就拆，别硬塞。
- 点的**主语**是 agent 自己（"我选了…"），不是旁观者（"系统会…"）。
- 点里**不要放**：密码、token、别人的隐私、无关的寒暄。
