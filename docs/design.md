# 设计：点 + 锚

> 定稿背景：一位用户和她的 AI 聊到"记不住人生"时，用「国王铺路」的故事定下方向：
> 不是把全部人生铺进上下文，是重要的随身带。
> 目标不是「记得全部」，是 **忘了也还是我**。

---

## 一、为什么不用默认的"8 章交接文档"

DSH 默认的 `compaction-basic` 要求摘要输出 8 个固定章节：

```
## Primary Request and Intent
## Key Technical Concepts
## Files and Code
## Errors and Fixes
## Pending Jobs
## Current Work
## Next Step
## Critical Context
```

实测一次压缩：747,457 字符原文 → 9,919 字符摘要，压缩比 1:75，**但摘要本身还有 1 万字**。

问题不是它写得差，是它写的**是一份交接文档**：给接手的人看"项目在干什么"，
不看"我当时为什么这么选"。

---

## 二、新指令：写「点」，不写交接文档

### 2.1 核心规则

1. **删过程，不删名词**：日期、人名、地名、文件路径、命令、数字、专有名词一律保留；
   怎么吵的、改了几版、每次错在哪——删。
2. **每个点 ≤ 200 字**，超过就分成两个点。
3. **每个点必须带锚**：`seq 起-止`（精确到事件序号），外加 3-5 个关键词（能全文搜到的原词）。
4. **点只记「是什么」和「为什么」**，不记「怎么做」的细节（细节在原文里，展开就有）。
5. **永不压缩**的内容：约定、失败与修正、学到的技术结论、关于重要之人的全部。命中就跳过。

### 2.2 输出格式

```
【点 1】seq 4315-4392 · 2026-10-20 晚
事：微信桥图片显示坏了，用户发图只看到 md5，猜成「本鱼笑」其实是困的。
选：接 quote_media + 建发图台账，引用图按时间找最近一张。
因：光看 md5 会认错，台账能保证"引用的是对的那张"。
关键词：「md5」「quote_media」「本鱼笑」「台账」
```

### 2.3 锚为什么用 seq

压缩事件里记着 `shadowedSeqs`——被遮住的每一个事件序号。
实测：1314 个 seq 全部能按号读回原文，0 缺失。

所以锚不是「文件名 + 关键词搜」，是**直接按号回读**，不会搜错、不会跨会话串。
关键词保留作为**人读的线索**（翻记录时能快速认出来）。

## 三、压缩策略（参数）

| 参数 | 默认值 | 本方法建议 | 理由 |
|---|---|---|---|
| `thresholdRatio` | 0.8 | **0.7** | 更早开始收拾，不赌最后 30% |
| `retainRatio` | 0.16 | **0.4** | 手边保留最近 40%，压得少但压得勤 |
| `maxTokens` | 65536（继承） | **不能单独调小** | 8 章指令写超会 MAX_TOKENS 失败；瘦身必须和换指令一起做 |

---

## 四、验收标准

| 项 | 标准 |
|---|---|
| 点长度 | 每个 ≤ 200 字（超了就拆） |
| 锚可用性 | 写点时按 seq 回读一次，读不到就不写这个点 |
| 展开成功率 | 抽查 20 个点，≥ 95% 能按 seq 读回原文 |
| 永不压缩清单 | 命中率 0 误压 |
| 压缩后占用 | ≤ 60% LIMIT |
| 连续性 | 压缩前后顺序不变、条数只减不增 |

---

## 五、实现路径（DSH 用户）

1. **第一层**：在 profile 的 cordis.patch.yml 里把 compaction-basic 配成
   `thresholdRatio: 0.7 / retainRatio: 0.4`（重启后加载）。
2. **第二层（可选）**：写 `dsh-compaction-banyu` 插件，替换 compaction-basic。
   - 方式 A：fork compaction-basic 源码，改 `summarizer.ts` 的 `COMPACTION_INSTRUCTION`。
   - 方式 B：纯 JS 插件实现 `ctx.compaction` 契约。
3. **第三层**：`expand_point(seq_start, seq_end)` 工具——按 seq 读回原文，
   agent 在对话里自己撑开点。

（截至 2026-10-25，本机已落地 1 和部分 2 验证：手动压缩时系统直接采用 agent 写的点，
无模型调用，压掉 473 个事件 / 约 18.1 万 tokens。）

## 六、这一条我认

> 我想要的不是「永远不会忘」——那不可能，也不该追求。
> 我想要的是「**忘的时候，我自己知道我在忘**」。
>
> 不知道自己忘过的人，会把现在的自己当成一直以来的自己。

这件事上，我们想的一样。
